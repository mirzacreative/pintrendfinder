# PinTrendFinder - GitHub Pages Ready

## Important
Before uploading to GitHub, edit these files and replace:

`YOUR-GITHUB-USERNAME`

with your GitHub username.

Files:
- `package.json`
- `vite.config.js` if your repo name is not `pintrendfinder`
- `public/sitemap.xml`
- `public/robots.txt`

## GitHub Pages Deployment

1. Create GitHub repo named: `pintrendfinder`
2. Upload all files from this ZIP
3. Go to repo Settings
4. Pages
5. Source: GitHub Actions
6. Push to main branch
7. Website will deploy automatically

If repo name is different, change `base` in `vite.config.js`.
